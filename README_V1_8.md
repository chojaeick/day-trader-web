# DAY TRADER WEB V1.8 — Tabbed UI

Main UI is split into four top-level tabs.

1. Trading
- NASDAQ / Semiconductor / Market Mode / Data
- Auto Universe and EXTREME exclusions
- Score refresh / Manual market rescan
- TOP10
- Intraday focus, 1m/5m charts, signal, position management

2. Research
- Historical Validation Lab
- Weight Study
- Paired Fold / RS Paired Study
- Robustness Ranking
- Rolling Walk-forward
- Relative Strength Sensitivity
- Regime / time-window diagnostics

3. Archive
- Daily Ranking Archive
- T-10 / T-1 / T+7 / T+30 / T+60 / CLOSE
- MANUAL and MANUAL_SCAN snapshots
- Date / snapshot ranking lookup

4. Live Validation
- Live TOP10 snapshot validation
- +30m / +60m / current-close performance

Safety
- V1.7.1 scan-3 market rescan behavior preserved.
- Trading score weights unchanged.
- No automatic orders.
