# DAY TRADER WEB v1.4.1

Changes
- Broader universe discovery: ALL + NYSE + NASDAQ + AMEX rankings.
- Target universe increased to ~40 names.
- Minimum discovery dollar-volume threshold relaxed to $5M.
- Core vs Auto-discovered names are shown separately.
- Discovery table shows volume rank, dollar-volume rank, discovery score, and chase risk.
- Extreme movers receive a chase-risk penalty in discovery scoring.
- Existing V1.3.2 timestamp fix and V1.4 dynamic WebSocket refresh are preserved.
- No auto-order functionality.
